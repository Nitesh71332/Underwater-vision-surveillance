# Results

This folder contains the final quantitative results generated during the project.

## Files

### final_results.csv

Contains the final evaluation results for the three datasets,including:

- Precision
- Recall
- mAP@0.5
- mAP@0.5:0.95

### runtime_results.csv

Contains inference-time measurements and FPS for the final models.

### model_size_results.csv

Contains the size of the final YOLOv8n model checkpoints.

### final_comparison.csv

Contains the comparison between the final configurations and the relevant baseline results.

## Final Evaluation

The project evaluated:

- DIATAquarium
- Aquatic Plant
- Well

Each dataset was evaluated separately because the datasets have different class structures and characteristics.

## Main Evaluation Metrics

- Precision
- Recall
- mAP@0.5
- mAP@0.5:0.95
- Inference time
- FPS
- Model size

The results were used to study the effect of underwater image enhancement and YOLOv8n detection performance.
